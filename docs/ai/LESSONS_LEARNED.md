# Lessons Learned

Prefer storing lessons in HiveMind.

Use this file only:
- when HiveMind is unavailable,
- for portable repository-level lessons,
- for recurring project failure patterns that should travel with the repo,
- for insights about capture/projection/category behavior that matter across fresh checkouts.

Keep entries short and actionable.

## Template

```text
Date: YYYY-MM-DD
Area: graph | projections | capture | scans | storage | runtime | docs
Lesson: concrete thing learned
Trigger: what exposed the problem or insight
Rule/Action: what to repeat or avoid next time
```
